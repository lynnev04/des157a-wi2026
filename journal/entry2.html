January 28, 2026

Best Practices for Modals / Overlays / Dialog Windows by Naema Baskanderi discusses the best ways to utilize modal windows. The article defines a modal window as an element that sits on top of an application’s main window. It disables the main window but keeps it visible with the modal window as a child window in front of it. Users need to interact with the modal window before they can return to the parent application. It can be useful to use a modal window when you want to grab the user’s attention, need user input, and show additional information in and not in context. Along with the previous information, I also learned the proper anatomy of a modal window, which consists of an escape hatch (e.g. close button), descriptive title, button, sizing, location, focus, and user initiated. It is important to include clear button labels and to not use more than 50% of the screen when placing one.
